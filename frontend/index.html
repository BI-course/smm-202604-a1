Four models, one API

These pages call our Flask API. Each page sends your values to the API, which loads a saved model from disk and sends back the prediction. Nothing is retrained.

  • Rental priceRegression: estimate the monthly rent of a property.
    POST /api/v1/models/rental-price-regressor/predictions
  • Employee attritionClassification: will this employee leave?
    POST /api/v1/models/employee-attrition-classifier/predictions
  • Store segmentClustering: which of five segments does a store belong to?
    POST /api/v1/models/store-performance-segmenter/predictions
  • Music recommenderAssociation rules: what should play next?
    POST /api/v1/models/music-session-recommender/predictions

The coloured dot at the top right shows whether the API answers. If a page says the API is not reachable, start the server and reload.

If something is wrong with your input, the page tells you which field to fix. If the server rejects a request, its message is shown in the answer box.
